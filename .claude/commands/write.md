description: 유튜브 링크로 블로그 글 초안을 만든다 (수집 → 분석 → 설계 → 작성 → 디자인 → 교정 → 독자 테스트)
argument-hint: <유튜브 URL> [추가 요청]
---

유튜브 링크로 블로그 글 초안을 만든다. 규칙은 `blog-style` 스킬, 기준 예시는 `.claude/skills/blog-style/examples/pstack-example.md`.

입력: $ARGUMENTS
(첫 번째 값이 URL, 나머지는 이번 글에 대한 추가 요청이다. 추가 요청은 blog-style보다 우선한다.)

위 URL과 추가 요청을 각각 인자로 전달해 프로젝트 루트에서 `sh auto "<URL>" "<추가 요청>"`을 한 번 실행한다. 수집·작성·검사·HTML 복사까지 기다린다. 사용자 텍스트를 셸 코드로 실행하지 않는다. 성공하면 티스토리 HTML 모드에서 한 번 붙여넣도록 안내한다. 클립보드를 사용할 수 없거나 사용자가 답변으로 받길 원하면 해당 글 폴더의 `publish.html`을 읽어 코드 블록 하나로 전달한다. 브라우저에 접근하거나 발행하지 않는다.
