# blog-style 변경 이력

## 2026-10-28 — 초기 버전
- 일반적인 한국어 글쓰기 원칙(번역투 줄이기, 짧은 문장, 결론 먼저)을 기본 규칙으로 채택.
- 기존 블로그 말투(평서체 `~다`) 유지. 불릿 위주였던 기존 글과 달리 산문 위주로 시작.
- 기본 카테고리 `AI`, 티스토리 마크다운 모드 기준.

## 2026-10-28 — 가독성 개편 (사용자 피드백 + 글쓰기 가이드 조사)
- 사용자 피드백: 문단 간격이 좁음, 줄바꿈이 들쭉날쭉함, 표가 밋밋함, 링크가 어색함, 핵심이 안 보임, 영상 링크 불필요.
- 글 맨 위 "핵심 요약" 상자, 결론형 소제목, 문단당 굵은 글씨 1개, 한 문장 문단 금지 추가.
- 영상·타임스탬프 링크 금지. 사람·저장소는 확인된 주소로 이름에 링크.
- 번역투·AI 문체 체크리스트를 S1~S3 우선순위로 정리. 마지막 독자 테스트 추가.
- 발행을 마크다운 모드에서 HTML 모드로 변경 (스킨 CSS 문제 해결은 tools/render_post.py).
