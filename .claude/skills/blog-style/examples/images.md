## 이미지 1: 하네스 5층 구조
- 위치: Q3 섹션, "아래층으로 갈수록 강해지는 구조다" 문단 다음
- 목적: 아래층일수록 규칙이 강하게 지켜진다는 것을 한눈에
- 비율: 16:9 (1200×675)
- 대체 텍스트: 코드베이스부터 스타일 가이드까지 다섯 층으로 쌓인 하네스 구조
- 프롬프트 (영문): A five-layer stacked pyramid viewed slightly from the side. The bottom layer is the widest and darkest blue, each layer above gets narrower and lighter. One simple icon per layer from bottom to top: building blocks, a magnifying glass, a document with checkmarks, a wrench, a color palette. Flat vector illustration, clean white background, blue color palette (#3d62ce accents), soft shadows, modern tech blog style, no text.
- 캡션: 아래층일수록 강하다 · 1 코드베이스 · 2 린트 · 3 규칙 파일 · 4 스킬 · 5 스타일 가이드
