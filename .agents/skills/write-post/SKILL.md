# 블로그 글 작성과 복사

영상 링크와 글 작성 요청을 받으면 프로젝트 루트에서 `sh auto <URL> [추가 요청]`을 직접 한 번 실행하고 완료를 기다린다. 링크와 요청은 각각 하나의 인자로 안전하게 전달한다. 이 명령이 자막 수집, 여섯 역할의 작성·검토, 로컬 초안 저장, HTML 변환과 클립보드 복사를 수행한다.

이미 완성한 글의 복사만 요청받으면 해당 글 폴더를 확인하고 `sh copy-post --ready posts/<글 폴더>`를 실행한다. 이 경로는 별도 메뉴 없이 본문과 정지 도식을 함께 복사한다. 글은 로컬 posts 저장소에 보관한다.

성공하면 티스토리 HTML 모드에서 한 번 붙여넣으면 된다고 한국어로 안내한다. 클립보드 접근이 실패하면 복사 실패를 알리고 생성된 publish.html을 제공한다. 사용자가 채팅에서 바로 복사하기를 원하면 그 파일의 실제 본문 전체를 HTML 코드 블록 하나로 제공한다. 브라우저 제어나 계정 접근은 필요하지 않다.
