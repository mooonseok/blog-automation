# blog-style 변경 이력

## 2026-10-28 — 초기 버전
- 일반적인 한국어 글쓰기 원칙(번역투 줄이기, 짧은 문장, 결론 먼저)을 기본 규칙으로 채택.
- 기존 블로그 말투(평서체 `~다`) 유지. 불릿 위주였던 기존 글과 달리 산문 위주로 시작.
- 기본 카테고리 `AI`, 티스토리 마크다운 모드 기준.

## 2026-10-28 — 가독성 개편 (사용자 피드백 + 글쓰기 가이드 조사)
- 사용자 피드백: 문단 간격이 좁음, 줄바꿈이 들쭉날쭉함, 표가 밋밋함, 링크가 어색함, 핵심이 안 보임, 영상 링크 불필요.
- 글 맨 위 "핵심 요약" 상자, 결론형 소제목, 문단당 굵은 글씨 1개, 한 문장 문단 금지 추가.
- 영상·타임스탬프 링크 금지. 사람·저장소는 확인된 주소로 이름에 링크.
- 번역투·AI 문체 체크리스트를 S1~S3 우선순위로 정리. 마지막 독자 테스트 추가.
- 발행을 마크다운 모드에서 HTML 모드로 변경 (스킨 CSS 문제 해결은 tools/render_post.py).
- 출처는 references.md.

## 2026-10-28 — 메타 문장 금지, 빈 줄
- 사용자 피드백: 출처의 "현재 배포본의 동작은 별도로 확인하지 않았다" 같은 말은 절대 넣지 말 것. 문단 사이 빈 줄이 여전히 없음.
- 8장에 S0(절대 금지): 작성 과정·검증 여부에 대한 메타 문장. 출처는 "- 영상: 채널명, 「제목」 (날짜)" 한 줄로 고정.
- 빈 줄은 render_post.py가 티스토리 빈 문단(`<p data-ke-size="size16">&nbsp;</p>`)으로 넣는다 (인라인 margin은 붙여넣을 때 지워짐).

## 2026-10-28 — 3차 개편: 재창조·숏폼·부품 디자인
- 조사: 인용·박스 디자인 레퍼런스, 인기 블로그·뉴스레터 9곳의 문체 (결론: 말투보다 문단 길이·빈 줄)
- 말투 평서체 `~다` 유지 (사용자 선택). 해요체·합니다체 금지
- 고정 템플릿: 도입 훅 → :::summary → Q1~Q3(질문 → 굵은 한 줄 답 → 설명·예시 → :::takeaway) → 바로 써먹기 → 마무리 → 출처 한 줄
- 문단 1~2문장(최대 3), 본문 1,000~2,500자, `>`·`---` 금지, 부품 문법 도입
- 이미지 규칙과 공통 이미지 스타일, images.md 형식
- 기준 예시 examples/pstack-example.md (+ images.md)
- tools/lint_post.py로 기계적 검사

## 2026-10-28 — 디자인을 티스토리 자체 서식으로 (렌더러)
- 사용자가 붙여넣은 결과: flex 배치·원형 번호·테두리·그라데이션 형광펜이 모두 지워지고 색·배경색만 남음
- 발행된 티스토리 글 조사: 살아남는 인라인 스타일은 color, background-color, text-align 정도. 나머지는 data-ke-* 자체 서식
- 부품 문법은 그대로 두고 출력만 변경: summary·팁·주의·용어 = 인용 style3 박스, takeaway = 인용 style1(가운데 따옴표),
  quote = 인용 style2(세로선), steps = ①② 번호 문단, 표 = style11, 형광펜 = 배경색
- render_post.py의 sanitize()가 허용 목록 밖 스타일을 지워 미리보기가 실제 결과와 같게 함

## 2026-10-28 — 주인공 설명 필수
- 사용자 피드백: "pstack이 뭔지 전혀 파악 못 하겠다. 설명 자체가 너무 줄었다" (-4 글이 '검증 습관' 일반론으로 빠짐)
- 원칙: 주인공(도구·개념) 설명은 버리는 대상이 아니다. 일반론으로 바꾸면 실패
- Q1 고정: "<주인공>은 무엇이고 어떻게 동작할까?" + 필수 요소(한 줄 정의, 왜 생겼나, 구성 요소, :::steps 동작 흐름, 비교, 한 줄 정리)
- 분량 1,800~3,500자로 상향. editor는 Q1 필수 요소를 자르지 않음. reader는 주인공을 설명 못 하면 FAIL
- 기준 예시 Q1 재작성

## 2026-10-28 — im-not-ai 차용
- 사용자 요청: 스크립트 실행 시 글 작성 단계에서 im-not-ai를 차용
- 8-1장 신설: humanize-korean quick-rules를 writer·editor가 처음부터 적용. E-1(장문 섞기) 제외, 부품 예외, D-3 열거 도입 회피
- lint_post.py에 C-11(오류), E-2·I-4·C-8·D-8·D-1·D-3(경고) 검사
- 기준 예시에서 연결어미 쉼표 4곳과 '결국 핵심은 하나다'(D-8) 수정

## 2026-10-29 — 출처·마무리 행동 과제 제거
- 사용자 요청: 영상 주제로 새로운 글을 창작하므로 자동 출처 목록과 “오늘부터 해볼 것”을 제거.
- 고정 템플릿, curator·writer·editor, 기준 예시에서 두 섹션을 빼고 자연스러운 결론으로 끝냄.
- lint는 출처·체크리스트의 부재를 오류/경고로 처리하지 않으며, 자동 출처 목록과 마무리 과제 제목을 검사.
- 이미지 계획에 주제 일러스트와 설명 도식 구분. 생성·호스팅은 아직 조사·추천 단계임을 명시.
