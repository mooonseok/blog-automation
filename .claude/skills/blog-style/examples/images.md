# 이미지 (pstack-example.md용 제작 명세)

## 이미지 1: 하네스 5층 구조
- 위치: Q3 섹션, 아래층으로 갈수록 규칙이 강해진다는 설명 다음
- 제작 방식: 생성 API 없이 SVG 코드 → 로컬 PNG 변환
- 파일: images/image-1.svg → images/image-1.png (designer가 작성할 파일명)
- 구성: 코드베이스, 린트, 규칙 파일, 스킬, 스타일 가이드를 아래부터 차례로 쌓고, 아래층일수록 넓게 표현
- 색상: 네이비 #18263d / 포인트 #22456b / 연한 면 #e9f0fa / 배경 #ffffff
- 대체 텍스트: 다섯 층으로 쌓인 하네스 구조. 아래층일수록 규칙을 강하게 보장한다.
- 캡션: 아래층일수록 강하다 · 코드베이스 → 린트 → 규칙 파일 → 스킬 → 스타일 가이드
